BEES WEEK 13 — START HERE

1. Extract the whole ZIP before running anything.
2. Install a JDK 17 or newer, with java and javac on PATH.
3. Windows: open Command Prompt in this folder and run run.bat.
   Linux/macOS: open a terminal here and run bash run.sh.
4. Run test.bat (Windows) or bash test.sh (Linux/macOS) to check the code.

Main files:
- src/ and Assets/: complete runnable application.
- docs/design-patterns.pdf: required Strategy / Simple Factory diagrams.
- docs/WEEK13-TECHNICAL-NOTES.md: code locations, snippets, trade-offs,
  parallelism explanation and a demonstration route for the worksheet.
- docs/CHANGES-FROM-WEEK7.md: what changed and what was retained.
- docs/VERIFICATION.md and evidence/: actual test results and screenshots.
- README.md: controls, command-line options and setup.

New controls: P changes the foraging policy; C compares both policies on four
paired seeds. The comparison runs separately from the live colony.

The refreshed Bee Meadow view adds shaded terrain and trees, clearer bees and
flowers, hover/selection feedback, a grouped inspector and live honey history.
The original simulation rules and seeded experiment results are retained.
